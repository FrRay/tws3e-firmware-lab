# vivo / iQOO TWS 固件研究

这里整理了 vivo 耳机的现成固件、本地安装 App，以及解包和修改固件的工具。TWS 3e 可以直接下载下面的文件安装；其他型号的固件放在[资料库](library/README.md)。

项目从一次 3e 升级推送开始：先查更新有没有改动降噪，再定位降噪参数，制作修改包，最后刷入耳机做对照。完整经过见[研究记录](docs/progress.md)。

## 下载并安装

### 1. 下载 App 和对应型号的固件

[下载 vivo 耳机本地固件版 App](downloads/app/vivotws_local_FW.apk?raw=true)

TWS 3e v2.6.3 的文件如下。选好一份，再按下一步操作。

| 固件 | 改了什么 | 已有反馈 |
|---|---|---|
| [官方原版](downloads/TWS3e/v2.6.3/original.bin?raw=true) | 原始 v2.6.3，参数为 1.00 | 作为比较基准，也用于恢复原参数 |
| [0.50 倍](downloads/TWS3e/v2.6.3/ff-0.50.bin?raw=true) | 把前馈降噪参数减半 | 刷入后降噪明显减弱 |
| [0.99 倍](downloads/TWS3e/v2.6.3/ff-0.99.bin?raw=true) | 把同一参数降低 1% | 已制作，供对照 |
| [1.01 倍](downloads/TWS3e/v2.6.3/ff-1.01.bin?raw=true) | 把同一参数提高 1% | 已刷入，反馈没有变砖 |
| [1.25 倍](downloads/TWS3e/v2.6.3/ff-1.25.bin?raw=true) | 把同一参数提高 25% | 已制作，等待听感反馈 |
| [1.50 倍](downloads/TWS3e/v2.6.3/ff-1.50.bin?raw=true) | 把同一参数提高 50% | 已制作，等待听感反馈 |

TWS3、TWS3 Pro、TWS4 的历史固件见[其他型号下载](library/README.md)。按自己的型号选文件，安装时使用下面同一套本地文件流程。

### 2. 在手机上准备文件

安装下载的 APK，把选定的完整固件文件改名为 `update.bin`，放到手机内部存储的 `vivotws` 文件夹：

```text
内部存储/
└── vivotws/
    └── update.bin
```

对应路径是 `/sdcard/vivotws/update.bin`。保留一份带原文件名的备份，方便之后切换倍率。

### 3. 打开 App 更新耳机

完全退出 App 后重新打开，连接耳机，进入固件更新页面，点击开始更新。按 App 提示放置耳机、满足电量要求，等到更新完成并重新连接。

这个 App 固定读取上面的 `update.bin`。要换另一个固件，就替换该文件，再重新打开 App。安装提示和常见问题见[手机操作图文步骤](docs/3e-workflow.md)。

## 这些倍率会带来什么变化

它们改的是同一个降噪参数。0.50 倍刷入后，实验者听到降噪明显减弱，说明这个参数确实能影响实际效果。1.01 倍已经刷入；1.25 和 1.50 的听感反馈还在收集。

倍率表示这个参数放大或缩小多少。选 1.50，也可能遇到某些声音压得更好、另一些声音反而更明显，所以比较时应听实际留下了多少噪声。测试中出现尖锐声或不适就取下耳机，结束该次测试。

## 想研究或制作自己的固件

从[制作工具说明](tools/README.md)开始。里面有环境安装、检查原包、解包、制作和校验命令，Python 与 7-Zip 都在这一步准备。

抓包、寻找旧版、对照 SDK 和检查修改位置的做法，可以继续用在其他 vivo / iQOO 耳机上。资料库已有 TWS3、TWS3 Pro、TWS4 的 12 份固件，方便比较版本。3e 的 `oviV` 与这些样本的 `APPUHDR5` 分别走 BES 和 QCC 分析路线，详见[解包与参数定位](docs/research.md)。
