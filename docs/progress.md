# 研究进展（截至 2026-10-26）

## TWS 3e

| 项目 | 当前结果 | 证据层次 |
|---|---|---|
| v2.6.3 OTA 解包与重打包 | 长度、累计 CRC、镜像 CRC、内部 CRC 已复核；中性重建完全一致 | 文件与原始指令离线验证 |
| 前馈比例字段 | 启动初值为 1.0；与同芯片 SDK 的 `g_ff_adaptive_gain` 对应 | 符号重定位、机器码与受控执行 |
| 1.01 实验包 | 使用者称刷入后未变砖 | 用户反馈，未独立取得完整安装日志 |
| 0.50 对照包 | 使用者称降噪明显变弱 | 用户主观对照，无入耳测量 |
| 0.99 / 1.25 / 1.50 | 已制作并离线校验 | 未收到对应实机结果，不能写成稳定版本 |
| 室内低频优化 | 曾研究追加低频滤波节并完成离线候选；未确定声学收益 | 未纳入本仓库的安装产物或构建命令 |
| 验签与恢复 | 已定位应用 CRC 路径；真正启动程序未取得，数字签名和救砖仍未查明 | 不能据此宣称已破解签名或不会变砖 |

0.50 的反馈提高了“这个初值影响实机 ANC”的可信度；没有证明它从启动后始终不被覆盖，也没有证明增大倍率就会变好。

## 官方更新说明的核对

TWS 3e v2.6.3 日志为“双设备播放体验”和“系统稳定性”。固件中已定位双设备播放状态判断、切换请求防重复、设备及目标一致性检查；原始指令离线执行吻合。只有一个 3e 版本，不能把这些现存机制全部写成此次新增修复。

系统内有控制器异常检查及崩溃记录，不能单凭这些代码确定本次修复了什么。3e 没有旧版对照，不能借其他型号的结果宣布“3e 本次完全没动降噪”。

## 其他型号提供的参考

原研究比较了 12 份 QCC 固件、九次相邻升级：TWS3 一次、TWS3 Pro 一次、TWS4 七次。这个范围不包含 3e 的前后版本差分。

- 对应型号相邻版本的 QCC 静态 ANC 表未变；每份解析到十组、每组 212 个命名字段。字段数不是降噪频段数，也不代表预设业务相同。
- TWS3 2.12.2 → 2.12.6：ANC 硬件管理器改了小值增益恢复/过渡和状态记录。
- Pro 3.8.6 → 3.9.7：音乐处理链后级预设约 +12 → +9 dB；这是音乐链增益，不能写成 ANC 减少 3 dB。ADAU1860 指定控制区及引用表完成了对照，不能用 QCC 参数表代表整颗外置控制器。
- TWS4 多版改了语音处理和 DSP 时钟策略；2.58.5 另改 ANC 初始化、贴合检测、工作缓冲与音量/音频数据处理。底层新增硬件寄存器接口仍有未命名字段。

这些结果支持“部分升级确实改过 ANC 相关流程”，没有查实统一下调 ANC 的操作；也不能把所有升级概括成必然正向。其他型号的结构可帮助分类，但不能把其参数直接移植到 3e。

本仓库的可执行工具专注于 3e 的单参数实验。上述跨型号结果是历史摘要，尚未移植完整 QCC 复现工具与所有原始证据，欢迎按具体版本和区域补充复核。
